Out of scope entirely unless explicitly re-authorized: nutrition/calorie
tracking, social feeds, public leaderboards, XP/levels, paid APIs, telemetry,
AI coach, native iOS/Android builds in this phase.

v0.0.9 (Import/Export) is next, but is explicitly not started per the
handoff that authorized v0.0.8 -- it introduces free-form parsing, file
handling, and hostile-input surface that deserves a dedicated, attended
session rather than continuing unattended. "Move/reschedule" a planned
workout was explicitly deferred in v0.0.5 (see docs/DATA_MODEL.md) -- the
current Program model has no calendar-occurrence concept, and building one
wasn't part of that version's scope.
